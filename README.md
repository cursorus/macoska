# macoska

Твик для iPadOS 15 (Dopamine, rootless): верхняя панель в стиле macOS + изменение размера системного дока.

## Что делает
- Заменяет системный статус-бар панелью macOS: логотип Apple, название активного приложения (на домашнем экране — Finder), меню File/Edit/View/Go/Window/Help, справа батарея, Wi-Fi, поиск, пункт управления и дата.
- Панель встроена прямо в системный статус-бар, поэтому поворот, раскладка приложений и скрытие в полноэкранных приложениях работают как у стокового.
- Масштабирует иконки системного дока и его высоту (ползунок 0.8–1.6, нужен респринг).
- Настройки: Settings → macoska.

## Сборка
```
make package FINALPACKAGE=1
```
Схема rootless уже прописана в Makefile. Готовый .deb появится в `packages/`.

## Статус
v0.1.0, не проверено на устройстве. Хуки дока (`SBDockIconListView -iconImageInfo`, `SBFloatingDockView +defaultHeight`) написаны по памяти по заголовкам iOS 15, при необходимости будут подправлены.
